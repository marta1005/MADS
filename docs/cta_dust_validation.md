# CTA/BWB Validation Against BWB Standalone

This note records the validation workflow used to check that the MADS CTA case
is using the same resolved geometry as `BWB/parametrization/CTA` before running
DUST.

Note: the `AoA=5 deg` numbers in this file are historical validation
references. The heavy output folders from those transient checks were removed
after extracting the values. The current retained DUST baseline output is the
`AoA=3 deg`, `n_steps=80` case generated by `examples/cta_dust_doe.py`.

## Geometry Equivalence

Reference BWB command:

```bash
PYTHONDONTWRITEBYTECODE=1 MPLCONFIGDIR=/private/tmp/bwb_mpl \
./.venv/bin/python -m parametrization.CTA \
  --design-space cfd_june_14 \
  --output-dir /private/tmp/bwb_cta_current \
  --no-plots
```

MADS command:

```bash
PYTHONDONTWRITEBYTECODE=1 MPLCONFIGDIR=../MADS/.mplconfig \
PYTHONPATH=../MADS/src \
./.venv/bin/python ../MADS/examples/cta_geometry.py
```

Resolved mesh comparison:

```text
BWB:  /private/tmp/bwb_cta_current/export/cta_resolved_mesh.npz
MADS: MADS/outputs/CTA_case/export/geometry/cta_resolved_mesh.npz

upper_vertices max_abs = 9.280149981805e-10 m
lower_vertices max_abs = 9.279697010811e-10 m
camber_vertices max_abs = 9.279697010811e-10 m
quads max_abs = 0
x_airfoil max_abs = 0
```

The remaining differences are numerical roundoff. The geometry passed to DUST
from MADS is therefore equivalent to the BWB standalone CTA geometry.

The matching fix was to use the same positive/log interpolation law for
trailing-edge thickness in MADS that the BWB core uses for positive section
quantities.

## Force History And Step Count

The force history can be reconstructed from the DUST result HDF5 files by
summing `Components/Comp001/Solution/dF` over all panels. Pitching moment is
reconstructed as `sum(r_panel_center x dF + dMom)`, using the panel centers from
`Output/cta_aoa_05_geo.h5`.

For the validated `n_steps=100` case, `PostLoads` averages steps `80-100`.
The per-step history gives:

```text
CL/CD/CM within 2.0% of the 80-100 mean from step 56
CL/CD/CM within 1.0% of the 80-100 mean from step 67
CL/CD/CM within 0.5% of the 80-100 mean from step 76
```

Window comparison against the current `80-100` average:

```text
60-80 mean: CL -0.574%, CD -0.852%, CM +0.627%
70-90 mean: CL -0.232%, CD -0.346%, CM +0.254%
```

An additional historical `n_steps=120` check was run to let the wake convect
farther downstream. The output folder was removed after extracting the values.

`100-120` and returns:
