# CTA Case Outputs

This folder groups the reusable CTA/BWB case outputs generated from MADS.

## Structure

- `convergence/panel/`: DUST panel-method convergence results, force histories, plots, and last run files.
- `convergence/vlm/`: DUST vortex-lattice convergence results, force histories, plots, and last run files.
- `convergence/lifting_line/`: DUST lifting-line convergence results, force histories, plots, and last run files.
- `export/geometry/`: baseline CTA geometry export, IGES file, resolved mesh, station airfoils, and summary.
- `videos/parameter_promo/`: parameter-space visualization GIFs and previews.
- `doe_geometry/`: geometry-only DOE datasets and design-space tables.
- `doe_dust_70_baseline_aoa03/`: baseline DUST DOE-style run outputs.

Intermediate dry runs, check folders, and internal validation-only artifacts were removed.
